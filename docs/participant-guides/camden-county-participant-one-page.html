Your portal in one page

Use the portal to request transportation, follow each update, review confirmed ride details, and ask for changes or cancellations.

Five steps

1

Sign in

Enter your approved mobile number and the six-digit code sent by text. Accept the current rules when prompted.

2

New request

Choose ride type, date, pickup and arrival times, direction, and approved locations. Submit one date per request.

3

Track status

Pending means submitted. Acknowledged means under review. Only Confirmed means your trip is scheduled.

4

View details

Review route, timing, driver, vehicle, and messages. Reply in the request conversation if more information is needed.

5

Plans changed?

Open the ride and select Request a change or Request cancellation. Wait until that action is completed.

Before you submit

Complete + accurate
  • Read the ride type’s advance-notice rule.
  • Enter both requested pickup and required-arrival time.
  • Use only approved pickup/destination locations.
  • Do not include diagnoses or unnecessary medical details.

Need help?

Use the right channel
  • Non-urgent ride question: use the request conversation.
  • Immediate ride help: select Call urgent support in the portal.
  • Portal messages are not monitored for emergencies.
  • Emergency or immediate danger: call 911.
